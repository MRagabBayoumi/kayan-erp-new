# Kayan ERP — نظام كيان لإدارة موارد المؤسسات

> **اللغات والوثائق:** [English Version (README.en.md)](README.en.md) · [خارطة الطريق والتحليل الفجوي الشامل (ROADMAP.md)](ROADMAP.md)

نظام تخطيط وإدارة موارد المؤسسات (**ERP**) لشركة **Kayan** المتخصصة في استيراد وتوزيع إكسسوارات حريمي، توك شعر، مستلزمات زينة وهدايا من الصين إلى تجار الجملة والتجزئة في السوق المحلي.

تم بناء الواجهة الأمامية وتجربة المستخدم استناداً إلى أرقى معايير واجهات أنظمة الأعمال وتجربة عميل الويب لنظام **Odoo Web Client**، مع تخصيص كامل للغة العربية ودعم كامل لاتجاه اليمين إلى اليسار (RTL).

## 🛠️ الحزمة البرمجية والتقنيات (Tech Stack)

- **Backend:** [Laravel 13](https://laravel.com) · [PHP 8.5](https://php.net) (معتمد عبر Herd Lite)
- **Database:** [MySQL 8.0](https://mysql.com) — قاعدة البيانات النشطة: `kayan_erp`
- **Frontend Architecture:** Blade Components & Partials
- **Styling:** CSS Design Tokens (`erp.css`) + Tailwind CSS v4 + Vite v8
- **Typography:** خط [Cairo](https://fonts.google.com/specimen/Cairo) للواجهات العربية مع أرقام جدولية (`tabular-nums`) للحسابات والباركود
- **Testing & Quality:** [Pest PHP](https://pestphp.com) (**165 اختباراً ناجحاً بنسبة 100% مع 1,124 تأكيداً**) + [Laravel Pint](https://laravel.com/docs/pint)
- **Printing Engine:** محرك Python مدمج للطباعة الحرارية المباشرة (Direct Thermal Printing) لقوالب الباركود والفواتير.

## 🎨 مميزات تجربة المستخدم ونظام التصميم (UI/UX Highlights)

### 1. تجربة مستوحاة من Odoo Web Client
- **شريط علوي موحد (Universal Topbar):** بلون البرغندي/البنفسجي الداكن العميق (`#714B67`) مع محرك بحث شامل سريع (`Ctrl+K`)، تنبيهات، وقائمة مستخدم مدمجة.
- **مطلق التطبيقات 3×3 (App Launcher Modal):** نافذة تنقل منبثقة سريعة بين وحدات النظام الأساسية، تدعم مفتاح `Escape` للإغلاق وتأثير غشاوة الخلفية.
- **لوحة التحكم السفلية (Odoo Control Panel):** شريط المسار (Breadcrumbs)، ومفاتيح تبديل طرق العرض (List, Kanban, Graph)، وأزرار الإجراءات السياقية.
- **شريط جانبي متجاوب وقابل للطي (Sidebar):** يدعم الطي إلى أيقونات فقط (64px) لتوسيع مساحة العمل، ويتحول إلى درج منبثق (Sliding Drawer) بطبقة تعتيم على الشاشات الصغيرة.

### 2. نظام السمات والكثافة (Themes & Density)
- **الوضع النهاري (Light Mode):** خلفية رمادية ناعمة (`#F0F2F5`) وأسطح بيضاء واضحة وحدود دقيقة مريحة للعمل النهاري.
- **الوضع الليلي (Dark Mode):** سمة كربونية داكنة متناسقة (`#121316`) ومتباينة دون نصوص رمادية باهتة لحماية العين.
- **كثافة العرض المؤسسية (Enterprise Density View):** مفتاح مستقل لتبديل كثافة الجداول والعناصر بين الوضع الافتراضي المريح (Comfortable) والوضع المؤسسي المكثف (Dense Compact) لعرض كميات أكبر من البيانات والصفوف.
- **حفظ فوري في المتصفح:** يتم حفظ السمات والكثافة في `localStorage` مع كود تهيئة مسبق في `<head>` يمنع وميض الشاشة عند إعادة التحميل.

### 3. الوحدات المنجزة والمحققة بالكامل
- **إعدادات الشركة والنظام (Phase 3A: `/settings`):** تخصيص بيانات الشركة، حفظ الهاتف الدولي، رفع واستبدال الشعار مع المعاينة الحية، وشارة حالة البرنامج.
- **إدارة المنتجات ونظام الاستيراد من إكسيل (Phase 4: `/products` & `/categories`):**
  - جدول منتجات متكامل مع البحث بالاسم وSKU والباركود وفلاتر التصنيف والحالة.
  - **نظام استيراد متكامل من إكسيل وCSV (`/products/import`):**
    - تنزيل قالب إكسيل منسق اختياري (`/products/import/template`) بترميز UTF-8 BOM الداعم للعربية.
    - مراجعة وتدقيق البيانات ومطابقتها سطر بسطر مع قاعدة البيانات `kayan_erp` قبل الحفظ.
    - تمييز الأصناف الجديدة، الأصناف القائمة لتحديث أسعارها، والأسطر غير الصالحة، مع خيار التحديث أو التخطي.
    - ترحيل البيانات المؤكدة فقط داخل معاملة ذرية موحدة (`DB::transaction`).
  - دعم كود الصنف الفريد (SKU) والباركود المفهرس (مع قبول تعدد الأصناف الخالية من الباركود دون تصادم).
  - هيكل تسعير ثلاثي: سعر التكلفة (استيراد الصين)، سعر الجملة للتجار، وسعر التجزئة، مع حساب هوامش الربح.
  - توليد آلي للأكواد الداخلية الخاصة بشركة كيان (Internal Barcode Generator).
  - نقطة نهاية فائقة السرعة لاستعلام الباركود (`/products/lookup-barcode`) تم قياسها بمتوسط استجابة **1.3 مللي ثانية**.

## 🚀 التشغيل والتطوير (Getting Started)

### المتطلبات الأساسية (Prerequisites)
- PHP >= 8.5 (معتمد عبر Laravel Herd Lite)
- Composer >= 2.8
- Node.js >= 20 & npm
- MySQL 8.0 مع قاعدة بيانات مسماة `kayan_erp`

### خطوات التثبيت والتشغيل المحلي

1. **تثبيت حزم الـ PHP والـ JavaScript:**
   ```bash
   composer install
   npm install
   ```

2. **بناء ملفات الواجهة الأمامية:**
   ```bash
   npm run build
   # أو أثناء التطوير التفاعلي:
   npm run dev
   ```

3. **تشغيل خادم التطوير:**
   ```bash
   php artisan serve
   ```
   *يعمل التطبيق افتراضياً على: `http://127.0.0.1:8000`*

4. **تشغيل الاختبارات والتأكد من الجودة:**
   ```bash
   # تشغيل اختبارات Pest
   php artisan test --compact

   # فحص وتنسيق الكود وفق معايير Pint
   vendor/bin/pint --format agent
   ```

## 🔒 قواعد الأمان وحماية البيانات (Safety Rules)

- **قاعدة البيانات النشطة:** النظام مرتبط حصرياً بقاعدة البيانات `kayan_erp`.
- **العزل التام:** يُمنع منعاً باتاً استهداف أو تعديل أو تهجير قاعدة البيانات القديمة المسماة `kayan` التابعة لبرنامج الديسكتوب.
- **حماية السرية:** عدم كتابة أو إظهار مفاتيح التشفير أو بيانات الاعتماد في مستودع الكود أو واجهات العرض.
- **حظر تزييف البيانات:** منع اختراع أو عرض بيانات مبيعات أو أرباح وهمية في لوحات التحكم والتقارير.
- **المعاملات الذرية وحماية المخزون:** منع أي خصم للمخزون أو إدراج عشوائي من الإكسيل إلا عبر عمليات ذرية متكاملة (`DB::transaction`) تضمن اتساق البيانات.
