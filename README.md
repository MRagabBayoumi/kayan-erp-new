# Kayan ERP — نظام كيان لإدارة موارد المؤسسات

> **اللغات والوثائق:** [English Version (README.en.md)](README.en.md) · [خارطة الطريق والتحليل الفجوي الشامل (ROADMAP.md)](ROADMAP.md)

نظام تخطيط وإدارة موارد المؤسسات (**ERP**) لشركة **Kayan** المتخصصة في استيراد وتوزيع إكسسوارات حريمي، توك شعر، مستلزمات زينة وهدايا من الصين إلى تجار الجملة والتجزئة في السوق المحلي.

تم بناء الواجهة الأمامية وتجربة المستخدم استناداً إلى أرقى معايير واجهات أنظمة الأعمال وتجربة عميل الويب لنظام **Odoo Web Client** و **Daftara**، مع تخصيص كامل للغة العربية ودعم كامل لاتجاه اليمين إلى اليسار (RTL)، وفصل معماري صارم (Zero Inline JS / Zero Inline CSS).

## 🛠️ الحزمة البرمجية والتقنيات (Tech Stack)

- **Backend:** [Laravel 12 / 13](https://laravel.com) · [PHP 8.4 / 8.5](https://php.net) (معتمد عبر Herd Lite أو XAMPP / Native PHP)
- **Database:** [MySQL 8.0](https://mysql.com) — قاعدة البيانات النشطة والمعزولة: `kayan_erp`
- **Frontend Architecture:** Blade Components & Partials مع فصل صارم للأكواد (Zero Inline JS / CSS)
- **Styling:** CSS Design Tokens (`erp.css`) + Tailwind CSS v4 + Vite v8 + خط [Cairo](https://fonts.google.com/specimen/Cairo) مع أرقام جدولية (`tabular-nums`)
- **Testing & Quality:** [Pest PHP](https://pestphp.com) (**165 اختباراً آلياً مغطياً لكافة الوحدات والطباعة والواجهات**) + [Laravel Pint](https://laravel.com/docs/pint)
- **Printing Engine:**
  - محرك الويب المدمج لطباعة المستندات (A4, A5, Thermal 80mm) بتهيئة CSS `@page` ديناميكية.
  - محرك Python مدمج للطباعة الحرارية المباشرة (Direct TSPL & Thermal Printing) لملصقات الباركود 38×25 مم و 38×15 مم مع دعم الدوران 90° و 270°.

## 🎨 تفاصيل الوحدات والوظائف المنجزة (Implemented Modules)

### 1. نظام الطباعة المتكامل وقوالب المستندات (Comprehensive Printing System)
- **دعم معتمد لـ 3 مقاسات رئيسية للمستندات:**
  - **A4 القياسي (210×297 مم):** مناسب للمكاتب، مراجعات الحسابات، وفواتير التوريد الرسمية.
  - **A5 الاقتصادي (148×210 مم):** مقاس مدمج يوفر 50% من استهلاك الورق ومثالي لفواتير المشتريات والمبيعات اليومية.
  - **الحراري 80 مم (Thermal Receipt 80mm):** فواتير الكاشير، إيصالات الاستلام، وأذون الصرف السريعة.
- **قوالب المستندات القابلة للتخصيص (`PrintTemplate` & `PrintTemplateService`):**
  - نموذج وقاعدة بيانات لقوالب الطباعة تدعم تخصيص الهيدر، الفوتر، إظهار الشعار، كود الباركود/QR، وهوامش وهوامش الورق.
  - تبويب مخصص في الإعدادات (`/settings?tab=print-templates`) لمعاينة القوالب وتعديل أبعادها ونصوصها.
- **طباعة فواتير المشتريات (`/purchases/{purchase}/print`):**
  - مسار مخصص وبيانات فعلية مباشرة من الفاتورة (بيانات المورد، مكتب الشحن، جدول الأصناف، الخصومات، الضرائب، الصافي، والمتبقي).
  - مفاتيح تبديل فورية في الهيدر للتنقل بين معاينة مقاسات A4 و A5 و 80mm قبل إرسال أمر الطباعة.
- **طباعة كشف حركة الصنف (`/products/{product}/ledger/print`):**
  - تقرير تفصيلي كامل لكافة حركات الوارد والمنصرف والتحويل مع الرصيد اللحظي التراكمي وتفاصيل الأطراف، يدعم A4 و A5 و 80mm دون تجزئة صفحات مخلة.
- **طباعة ملصقات الباركود الحرارية (Thermal Labels 38×25 مم & 38×15 مم):**
  - دعم اتجاه الطباعة الأفقي (Landscape) مع الدوران بزاوية 90° أو 270° ليناسب طابعات Xprinter والمقاسات الضيقة دون اقتصاص النصوص أو الباركود.

### 2. إدارة الأصناف وهيكل التسعير والاستيراد الذري (`/products`)
- **هيكل تسعير رباعي متقدم لنشاط الإكسسوارات:**
  1. سعر التكلفة (استيراد الصين بالعملة المحلية).
  2. سعر الجملة لتجار الإكسسوارات.
  3. سعر الموزع والوكيل (المبيعات الكبيرة).
  4. سعر بيع التجزئة (القطاعي للمستهلك).
- **التعبئة ووحدة القياس:** دعم عدد القطع في الطرد/الدستة وتنبيهات حد النواقص لكل صنف.
- **رصيد افتتاحي ذري:** تسجيل الرصيد الافتتاحي وتوزيعه آلياً على المستودع المحدد مع توليد دفعة مخزنية أولى (`inventory_batches`) لدعم نظام FIFO.
- **إعادة هيكلة واجهة تفاصيل الصنف (`/products/{product}`):**
  - إطار مخصص ومحمي للصورة `.erp-product-image-frame` يمنع تشوه الصور أو قصها.
  - فصل كامل لبطاقة صورة المنتج، بطاقة ملصق الباركود، وبطاقة الحذف لتجنب الضغط الخاطئ.
  - استجابة مرنة عند دقة 1080px تمنع حدوث أي قص أو طفح أفقي على شاشات اللابتوب والتابلت.
- **نظام استيراد الإكسيل المتقدم (`/products/import`):**
  - تنزيل قالب CSV منسق بترميز UTF-8 BOM لضمان التوافق مع Excel باللغة العربية.
  - مطابقة وتدقيق مسبق لكل سطر ومقارنة الأسعار القديمة والجديدة.
  - خيارات واضحة للمستخدم: استيراد كجديد، تحديث القائم، أو التخطي، مع الحفظ داخل معاملة ذرية `DB::transaction`.

### 3. منظومة المشتريات وتتبع التكلفة ودفعات الوارد (FIFO Purchases)
- **دورة الشراء المتكاملة (`/purchases`):**
  - تسجيل فواتير الشراء متعددة البنود مع ربط الصنف، الكمية بالدستة أو القطعة، وسعر الشراء الفعلي للشحنة.
  - ربط الفاتورة بمورد الصين أو المورد المحلي، ومكتب الشحن الدولي، وتحديد المستودع المستلم.
  - احتساب الخصومات، الضرائب، مصاريف الشحن الإضافية، المدفوع، والمتبقي كرصيد دائن على حساب المورد.
- **توليد دفعات المخزون الذرية (`inventory_batches`):**
  - مع كل فاتورة شراء مرحلة، يتم توليد دفعات مخزنية برقم الشحنة وتكلفة الوحدة، لتكون جاهزة لمحرك صرف FIFO في شاشة المبيعات والكاشير.

### 4. إدارة المستودعات وحركات المخزون (`/stock-movements`)
- تسجيل الحركات المخزنية بمختلف أنواعها: إيداع وارد، صرف، تسوية جردية، وتحويل بين المستودعات.
- كشف حركة تفصيلي لكل صنف يوضح نوع الحركة، الكمية، المستودع، الرصيد اللحظي بعد الحركة، ورقم الفاتورة أو المستند المرتبط.
- شاشة مراقبة نواقص المخزون (`/stock-alerts`) لمتابعة الأصناف التي اقتربت من نقطة إعادة الطلب.

### 5. إدارة الشركاء التجاريين (العملاء والموردين ومكاتب الشحن)
- واجهات متناسقة مع نوافذ منبثقة سريعة (Modals) لإضافة عميل أو مورد أو مكتب شحن مباشرة دون مغادرة الفاتورة.
- تحديث فوري للقوائم المنسدلة في النماذج بعد الحفظ مع حماية ضد الحفظ المزدوج (Double Submission Prevention).
- دعم بيانات مصانع الصين الخاصة: WeChat ID، هاتف دولي، فئات الخصم، وسقوف الائتمان.

### 6. نظام التصميم والمعمارية البرمجية الصارمة (Strict Blade Separation)
- **عزل مطلق للواجهات:** خالٍ تماماً من وسوم `<script>` المضمنة، ووسوم `<style>`، وسمات `style="..."` في كافة قوالب Blade (34 ملفاً مفحوصاً ومؤكداً عبر سكربت التدقيق الآلي `scripts/audit_blade_separation.cjs`).
- **تنظيم ملفات الأصول:** جافاسكريبت مستقل لكل صفحة داخل `resources/js/pages/` وملفات CSS لكل صفحة داخل `resources/css/pages/` مجمعة بكفاءة عبر Vite.

## 🚀 دليل التشغيل والتطوير (Getting Started)

### المتطلبات الأساسية
- **PHP:** >= 8.4 (معتمد رسمياً مع إضافات `pdo_mysql`, `mbstring`, `zip`, `gd`)
- **Composer:** >= 2.8
- **Node.js:** >= 20 & npm
- **قاعدة البيانات:** MySQL 8.0 مع قاعدة بيانات مسماة `kayan_erp`

### التشغيل السريع

1. **تثبيت الاعتماديات:**
   ```bash
   composer install
   npm install
   ```

2. **تهيئة البيئة وقاعدة البيانات:**
   ```bash
   # التأكد من تشغيل MySQL واستهداف قاعدة kayan_erp في ملف .env
   php artisan migrate --seed
   ```

3. **بناء أصول الواجهة:**
   ```bash
   npm run build
   # أو أثناء التطوير الحي:
   npm run dev
   ```

4. **تشغيل سيرفر التطبيق:**
   ```bash
   php artisan serve --port=8000
   ```
   *رابط النظام المباشر:* [http://127.0.0.1:8000](http://127.0.0.1:8000)

5. **فحص الجودة والمعمارية:**
   ```bash
   # التحقق من الفصل المعماري التام لقوالب Blade (Zero Inline JS/CSS)
   node scripts/audit_blade_separation.cjs

   # تشغيل حزمة الاختبارات الآلية الشاملة
   php artisan test
   ```

## 🔒 قواعد الأمان وحماية البيانات (Safety Rules)

- **قاعدة البيانات النشطة:** النظام مرتبط حصرياً بقاعدة البيانات `kayan_erp`.
- **العزل التام:** يُمنع منعاً باتاً استهداف أو تعديل أو تهجير قاعدة البيانات القديمة المسماة `kayan` التابعة للبرنامج القديم.
- **حظر تزييف البيانات:** منع اختراع أو عرض بيانات مبيعات أو أرباح وهمية في لوحات التحكم والتقارير.
- **المعاملات الذرية وحماية المخزون:** منع أي خصم للمخزون أو إدراج من الإكسيل أو تسجيل فواتير شراء إلا عبر عمليات ذرية متكاملة (`DB::transaction`) تضمن اتساق المخزون وحسابات الموردين.
- **فصل الأكواد المعماري:** استمرار الالتزام بنسبة 0% كود JS أو CSS مضمن داخل قوالب Blade للحفاظ على خفة وسرعة النظام وقابلية صيانته.
